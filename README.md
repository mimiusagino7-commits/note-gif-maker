# noteリアクションGIFメーカー

連続した画像に文字を重ね、ブラウザ内でGIFにする小さな静的Webアプリです。

## できること

- PNG / JPG / WEBP を最大12枚読み込み
- フレーム順の入れ替え・削除
- 「スキ♡ありがとう」などの文字プリセット
- 文字位置・文字サイズ調整
- GIF速度調整
- 480 / 600 / 800px の仕上がりサイズ
- アニメーションプレビュー
- GIF書き出し・保存
- 画像はサーバーに送らずブラウザ内で処理

## 使い方

`index.html` をブラウザで開くだけでも画面は確認できます。
GIFの書き出しには gifshot をCDNから読み込むため、インターネット接続が必要です。

## Netlifyへ公開する

### 方法A：Netlifyへ直接アップロード
1. `note-gif-maker` フォルダの中身をZIPにする
2. Netlifyの新規サイト作成画面で手動デプロイを選ぶ
3. ZIPまたはフォルダをアップロード

### 方法B：GitHub → Netlify
1. GitHubで新しいリポジトリを作る（例：`note-gif-maker`）
2. `index.html` と `README.md` をリポジトリ直下へ置く
3. Netlifyで「Import from Git」を選ぶ
4. 対象リポジトリを選択
5. 静的サイトなので Build command は空欄、Publish directory は `.` のままでOK
6. Deploy
